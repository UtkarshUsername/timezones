# Timezones

A simple timezone planner for coordinating time across cities.

[Open the app](https://timezones.lakebed.app)

## Features

- Compare a time range across multiple timezones.
- Add, remove, and reorder timezone rows.
- Light and dark themes with browser-saved settings.

## Development

Requires [Lakebed](https://lakebed.dev).

```sh
npx lakebed dev
```
